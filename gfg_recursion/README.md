# 🔁 Recursion — DSA Practice
> **From understanding recursion to recognizing reusable recursive patterns.**
This repository contains **22 recursion problems** solved in C++ from the
GeeksforGeeks Recursion practice set, progressing from **Basic → Easy → Medium → Hard**.

The purpose is not just to collect solutions, but to build a **reusable
reference for standard recursion patterns** that can be revisited while
solving future DSA problems.

## 💡 What This Practice Taught Me
> **Don't memorize the recursion — identify the state.**
The problems helped me practise identifying:
**Base Case → Current State → Choice/Transition → Smaller Problem → Result**
This makes the solutions easier to understand and the patterns easier to
reuse in unfamiliar problems.
